# HR Analytics Dashboard using Tableau

## Project Overview
This project focuses on analysing HR data and creating an interactive dashboard using Tableau to understand workforce trends and employee insights.

## Tools Used
- Tableau
- Data Visualization
- Calculated Fields
- Filters and Interactive Dashboards

## Key Analysis
- Total Employee Count
- Department-wise Employee Distribution
- Gender Distribution
- Salary Analysis
- Employee Attrition Analysis
- Workforce Trends

## Dashboard Features
- Interactive filters
- KPI cards
- Charts and visualizations
- Department-wise analysis

## Project Objective
To transform HR data into meaningful insights and support better HR decision-making through interactive Tableau visualizations.

## Conclusion
This project helped me improve my Tableau skills, data visualization techniques, and analytical thinking.
